SmalLoL: League of Legends esports, but small.
Portable version for Windows: nothing to install, no administrator rights needed.

1. Unzip this folder anywhere you can write to (Desktop, Documents, a USB stick).
2. Run SmalLoL.exe.

If Windows says "Windows protected your PC": the app is not code-signed yet.
Click "More info", then "Run anyway". If the file came from the internet you can also
right-click SmalLoL.exe, choose Properties, and tick "Unblock" first.

Needs the Microsoft Edge WebView2 Runtime. Windows 11 has it; most Windows 10 PCs
get it with Edge. If SmalLoL does not start, that is the usual reason.

Settings are kept in %APPDATA%\io.github.zaious.smallol\, and the web view's cache in
%LOCALAPPDATA%\io.github.zaious.smallol\. Delete those two folders and this one to remove
every trace.

SmalLoL reads match data from its data service (smallol-api.chroniclecore.com by default; you can
change it in Settings) and, once after start-up (you can switch it off in Settings),
api.github.com (to tell you about a newer version). It collects nothing.
This portable copy never updates itself: for a new version, download the new zip.
